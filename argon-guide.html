제미나이 4 아르곤, 초보자 한 장 정리

영상에서 말한 순서와 문장을 그대로 모았어요. 복사할 문장은 상자 오른쪽 위 복사 버튼으로 가져가세요. 체크박스는 눌러 두면 저장돼요. 기준일은 2026년 10월 27일이에요.

한 줄로

아르곤은 구글 제미나이의 새 모델(머리)이에요. 같은 머리를 제미나이 앱, AI 스튜디오, 안티그래비티, API 네 곳에서 쓸 수 있고, 어디서 쓰느냐에 따라 하는 일이 달라져요.

네 개의 문

  • 💬 제미나이 앱: 채팅과 문서 읽기. 모델 선택에서 4 아르곤 고르기 (구글 AI 프로·울트라 구독 기준)
  • 🛠 AI 스튜디오 빌드 모드: 말로 앱 만들기
  • 🤖 안티그래비티: 혼자 일하는 코딩 에이전트
  • 🔑 API 키: 내가 만든 서비스에 아르곤 붙이기

모델 선택에 안 보이면 아직 내 계정에 차례가 안 온 것일 수 있어요. 안티그래비티는 공식 페이지에 AI 프로·울트라에서 쓸 수 있다고 적혀 있지만, 울트라가 필요하다는 보도도 있어서 내 요금제에서 직접 확인하세요.

따라 하기 ① 긴 문서 검토

  • 제미나이 앱에서 모델을 4 아르곤으로 골라요.
  • 검토할 PDF를 올려요.
  • 아래 문장을 붙여 넣어요.
이 문서를 읽고 목적을 한 줄로 요약해줘. 각 부분을 평가하고, 부족하거나 빠진 내용을 찾아줘. 숫자, 날짜, 기술 설명이 서로 안 맞는 곳이 있으면 쪽 번호와 함께 알려주고, 심각한 순서대로 정리해줘.
  • 결과가 나오면 원본 문서와 직접 대조해요. AI가 틀린 걸 찾았다고 말할 때도 있어요.
  • 같은 대화에서 이어서 아래 문장을 보내요. 마지막 줄이 핵심이에요.
이어서 이 문서를 바탕으로 기술 문서를 새로 써줘. 개요, 구조, 구성 요소, 데이터, API, 성능과 안정성, 보안, 이전 계획 순서로 쓰고, 표와 제목을 넣어줘. 서로 안 맞는 내용은 마음대로 고치지 말고 표시해줘.

따라 하기 ② 말로 앱 만들기

  • 구글 AI 스튜디오를 열고 빌드 모드로 들어가요.
  • 모델을 4 아르곤으로 바꾸고 아래 문장을 붙여 넣어요.
먹은 음식을 문장으로 적으면 칼로리와 단백질, 탄수화물, 지방을 추정해 주는 모바일 웹앱을 만들어줘. 처음에 나이, 키, 몸무게, 목표를 입력하는 화면, 하루 칼로리를 보여 주는 대시보드, 추정값을 직접 고칠 수 있는 기능, 브라우저에 기록이 저장되는 기능을 넣어줘.
  • 만드는 과정이 끝나면 미리보기를 열어 직접 눌러 봐요.
  • 영양 수치는 AI가 짐작한 값이라 틀릴 수 있어요. 고칠 수 있게 만들라고 시킨 이유예요.
  • 마음에 안 드는 부분은 말로 고쳐 달라고 해요.

영상 제작자의 시연 방식을 참고했고, 문장은 한국어로 다시 썼어요.

따라 하기 ③ 에이전트로 일 시키기

  • 안티그래비티를 열고 새 작업 공간을 만들어요.
  • 모델을 4 아르곤으로 골라요. 요금제에 따라 선택지가 다를 수 있어요.
  • 연습용(중요한 파일이 없는) 폴더에서 아래 문장을 보내요.
브라우저에서 하는 우주선 슈팅 게임을 만들어줘. 마우스나 키보드로 움직이고, 적이 나오는 단계가 점점 어려워지게 해줘. 시작 화면, 일시정지, 게임 오버 화면도 넣어줘. 필요한 것을 설치하고, 실행해 보고, 오류가 나면 직접 고쳐서 돌아가게 만들어줘.

에이전트는 내 컴퓨터에서 파일을 만들고 명령을 실행해요. 처음엔 중요한 파일이 없는 곳에서 연습하세요.

API 키 받기 (개발자용)

  • 구글 AI 스튜디오의 API 키 페이지를 열어요.
  • Create API key를 눌러 키를 만들어요.
  • 나온 키를 복사해요.

공식 문서의 보안 규칙이에요.

  • 깃 같은 곳에 키를 올리지 않아요.
  • 웹이나 앱 코드에 키를 그대로 적지 않아요.
  • 환경 변수에 넣어서 읽어요.
  • 키는 Gemini API에서만 쓰도록 제한해요.
  • 결제 알림을 켜 둬요.

모델 이름은 gemini-4-argon 이에요.

값과 한도 (공식 문서 기준)

  • 입력과 출력을 합친 한 번에 다룰 수 있는 양: 약 100만 토큰(1,048,576)
  • 답 길이: 기본 65,536 토큰, 길게 쓰는 방식은 최대 1,048,576 토큰
  • 생각 단계: 낮음·중간·높음, 기본값은 중간. 높일수록 생각에 쓰는 양과 비용이 늘 수 있어요.
  • 입력은 글·그림·영상·소리·PDF, 답은 글로만 나와요.
  • API 가격은 100만 토큰당 입력 2달러·출력 10달러(2026년 11월 30일까지), 12월 1일부터 입력 4달러·출력 20달러. 생각에 쓴 토큰도 출력으로 계산돼요.
  • 무료 등급에서는 쓸 수 없다고 적혀 있어요. 결제를 켠 프로젝트가 필요할 수 있어요.
